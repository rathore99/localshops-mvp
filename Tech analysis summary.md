Tech analysis summary
Best fit: Custom React PWA
Pros:
Best UX for local search and reservations
Full control over marketplace model
Low cost if built on open source
Works offline / installable
Cons:
Requires development effort and backend setup
Shopify
Pros:
Quick store setup
Built-in commerce features
Cons:
Not built for multi-shop marketplaces
High cost for plugins and customizations
Poor fit for reservation-first local discovery

WooCommerce + marketplace plugin
Pros:
Marketplace support exists
Familiar if your team uses WordPress
Cons:
Heavy, less performant
More maintenance overhead
Plugin compatibility risk
Other options
Sharetribe: marketplace-focused but SaaS cost and vendor lock-in
Headless CMS + frontend: flexible but more complex
WordPress + Dokan: possible, but heavy for mobile-first local PWA
